## Что заблокировано / открытые вопросы

- WebKit Playwright не является полной заменой настоящего Safari/iOS Safari; финальная совместимость требует Safari Web Inspector, физического iPhone или BrowserStack.
- Auth coverage ограничен отсутствием безопасного существующего storage state/test user fixture для защищённых admin-маршрутов.
- Visual baselines могут зависеть от динамического контента, шрифтов и внешних CDN; перед использованием в CI нужна стабилизация данных.
- `BLOG_SOURCE=static pnpm build` падает из-за пустого `POSTS=[]` и ограничения Next.js 16 Cache Components для пустого `generateStaticParams`; стандартный Supabase build проходит.
- Необходимо отдельно решить найденные продуктовые проблемы: iOS input zoom на `/admin/login`, контраст главной страницы и Firefox console error от Cloudflare cookie.
