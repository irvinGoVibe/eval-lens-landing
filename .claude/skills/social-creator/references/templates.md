# Шаблоны постов и ритуалов

Скелеты — не догма. `[…]` = слот для факта/детали фаундера (мета-приём: живая мысль
человека). Реальные числа — только из источников правды/дебрифов. Продакшен-копия
LinkedIn/X — EN; Telegram — по аудитории.

---

## A. Хук-банк (первая строка = вся игра)

- **Контрарный:** «Most accelerators reject good startups for the wrong reason.»
- **Число/результат:** «We scored 1,000+ pitches. One signal predicted funding better than the rest.»
- **Show-your-work / провал:** «Our AI flagged a "deception" that wasn't one. Here's what we got wrong — and fixed.»
- **Проблема-узнавание:** «Your screening memo is written by whoever's least tired at 6pm.»
- **Feedback-разрыв:** «You sent your deck to 500 funds. You got silence. Here's what silence actually means.»

## B. LinkedIn — document-карусель (топ-формат)

```
Слайд 1 (превью, 50% усилий): <ХУК из §A> — крупно, 1 строка + под-строка обещания.
Слайд 2: Стейкс — почему это важно читателю-фаундеру (1–2 строки).
Слайд 3–N: Нумерованный фреймворк / шаги / разбор (1 идея на слайд, конкретика).
   [слот: реальная цифра из прогонов / дека]
Слайд N+1 (принцип): одна цитируемая строка (Unicorn-приём).
Слайд последний (CTA): «Save this» / «Bring your deck → [Telegram]» / «Try the live demo».

Тело поста (над каруселью): хук + 2–3 короткие строки + «Save it ↓».
CTA-ссылка → ПЕРВЫЙ КОММЕНТ (не в теле).
Голос: Yaroslav/Владислав от первого лица.
```

## C. LinkedIn — текст (личный, контрарный/«show your work»)

```
Строка 1: <ХУК>
Строка 2: пустая.
3–6: нарратив «я видел X → почему очевидное неверно → что на самом деле».
   [слот: конкретный кейс/число]
Финал: доброжелательный поворот или сухая шутка (Unicorn) + мягкий CTA/вопрос.
(Ссылок в теле нет; вопрос в конце фармит комменты в golden hour.)
```

## D. X — тред

```
Твит 1 (хук): обещает конкретную ценность/число. Без ссылок.
Твит 2–N (8–15): доставляют по одной мысли + реальные числа.
   [слот: agreement-rate AI↔человек / сколько питчей / вехи]
Твит N (саммари): 1 строка-принцип.
Твит финал: реплай-промпт («Which signal do you think matters most? 👇»).
Опц.: 15–45с видео фаундера отдельным постом.
```

## E. Telegram — broadcast + опрос

```
Broadcast (≤ 2 абзаца, живо):
«<хук/новость> ↓
<1–2 строки сути + эмодзи-акцент>
<ссылка/что делать>»

Опрос (нативный, highest-engagement):
Вопрос: «Какой сигнал в деке решает?»
Варианты: Проблема · Рынок · Команда · Traction
→ результаты обсуждаем в linked-группе.
```

## F. Ритуалы комьюнити (шаблоны, §6.1 канона)

### F1. «Score & Tell» — еженедельный тред (Telegram-группа)
```
📊 Score & Tell — <дата>
Выложи свежий скор своего питча по EvalLens Six и ОДНУ вещь, что подсветил AI.
Правило: под каждым — один конкретный совет соседу (не «круто»).
[закреп: как получить разбор → Try the live demo]
```

### F2. «Ask the Jury» — колонка-адвайс (LinkedIn/X/TG)
```
Заголовок: «Ask the Jury: <вопрос фаундера дословно>»
1) Переформулируй вопрос в одну строку.
2) Ответ нашим фреймворком (EvalLens Six) — прямой, evidence-first.
   [слот: как это читают наши линзы / реальный паттерн из прогонов]
3) «Как именно сделать / покажи пример» (First Round-приём).
4) CTA: «Задай свой вопрос → [форма/TG]».
```

### F3. «Live Teardown» — промо + рекап
```
ПРОМО (за 3–4 дня):
«<Дата> — Live Teardown. Один фаундер даёт дек, прогоняем через AI-жюри ВЖИВУЮ по
6 измерениям, разбираем комнатой. LinkedIn Live / X Spaces / TG.
Хочешь свой дек в эфир? → [заявка]»

РЕКАП (после):
«Разобрали дек <аноним/с согласия>. Что подсветил AI / что решила комната:
[3 буллета с реальными находками]. Клипы ↓»
(Режем эфир на 5–10 вертикальных клипов — приём 20VC.)
```

### F4. «Pitch Gauntlet» — ежемесячный лидерборд-челлендж
```
АНОНС:
«🏆 Pitch Gauntlet — <месяц>. Сабмить дек → AI-жюри даёт скор по EvalLens Six →
публичный ранг. Награда — топ-скору И лучшим за фидбек (не только победителю).
Дедлайн <дата>. Сабмит → [ссылка].»

ИТОГИ:
«Лидерборд <месяца>: [топ-3 с согласия]. Самый разобравший фидбек: [имя].
Что общего у топ-деков по данным: [1–2 паттерна]. Следующий заход <дата>.»
```

### F5. «State of the Pitch» — годовой тентпол-репорт (анонс-пост)
```
«We scored <N> pitches this year. Here's what kills them.
[3–5 буллетов: измерение, где деки проседают чаще всего; что отличает топ-дециль;
паттерны по стадии]. Full report ↓ (link in comments).»
Оговорка: «across the pitches EvalLens has scored» — не блефовать масштабом выборки.
Репак: карусель (LinkedIn) + тред (X) + broadcast (TG).
```

### F6. Event-recap (после ивента, напр. Нячанг)
```
Хук: «We planned two hours. The room kept us for three.»
3–5 буллетов: что было (методология → питчи → когортный разбор → лидерборд),
реальный трекшн (LOI / кейс переработки питча — по правилам публичности дебрифа).
Финал: «Next room? → [Telegram]».
Медиа: реальные фото/видео из папки ивента.
Репак: LinkedIn-карусель takeaways + X-тред + TG (пост + welcome новичкам с ивента).
```
