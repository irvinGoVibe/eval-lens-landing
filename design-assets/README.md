# design-assets

Рабочие исходники артов, вынесенные из `web/public` при технической оптимизации
(июль 2026): `*-source`, `*-preview-*`, `-2x/-4x`, `_demo-pool`, неиспользуемые
альтернативы. Ничто отсюда не раздаётся сайтом. Дерево путей сохранено 1:1 —
файл можно вернуть обратно простым `git mv` в `web/public/<тот же путь>`.
